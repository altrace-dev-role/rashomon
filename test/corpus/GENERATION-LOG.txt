test/corpus generation log. Counts only; no value from a dropped row is kept here.

Provenance. Each repository in repos.json was shallow-cloned (depth 1) and the
checkout verified to be at its commit_sha before any row was read (both builders
refuse otherwise). Licences were read from each repository's licence file; all
ten are MIT, Apache-2.0, BSD-3-Clause, or MIT OR Unlicense.

Rebuild, from the repository root, with CLONES holding one checkout per
repository named <owner>_<repo>:
  python3 -I test/corpus/tools/build_paths.py $CLONES /tmp/path-cand.jsonl
  python3 -I test/corpus/tools/build_shell.py $CLONES /tmp/shell-cand.jsonl
  go run ./test/corpus/cmd/scrubfilter -field path /tmp/path-cand.jsonl > test/corpus/paths.jsonl
  go run ./test/corpus/cmd/scrubfilter -field line /tmp/shell-cand.jsonl > test/corpus/shell.jsonl
  go run ./test/corpus/cmd/report -commit <classifier commit> -out test/corpus/reports
Both builders are deterministic (no RNG, no clock, sorted output); two runs were
compared byte for byte.
